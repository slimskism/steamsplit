# SteamSplit
The SteamSplit is a single controller split column staggered keyboard with a num pad in the middle.  It also has RGB underglow suuport.  It uses a raspberry pi pico for the controller.

It is a 3x6 layout with a three button thumb cluster, additionally two more keys are available as an encoder alternative adjacent the index finger position.  The three parts are connected via a 14 pin ribbon cable that due to an oversight in design must be twisted to fit.  A couple of different 3D printable case options are available.  All designs are for the left hand, and can be mirrored in slicer software to get the right hand side. 

Firmware can be found in the firmware file, or you can grab my fork of QMK to set up something else.
